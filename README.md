## Installation

To install dependencies, run:

`npm install`

## Development

To start the development server:

`npm run start`

## Build

For a development build:

`npm run build:dev`

For a production build:

`npm run build:prod`

## Linting

To check for linting errors:

`npm run lint`

To automatically fix linting issues:

`npm run lint:fix`

## Storybook

To start Storybook:

`npm run storybook`

To build Storybook:

`npm run build-storybook`

## Testing

To run tests:

`npm run test`

To run Storybook tests:

`npm run test-storybook`
